# 2026-10-18 工作日志

## 零点标定功能（新增）
- 首页新增「零点标定」入口（pages/index，蓝紫主题卡片 `.cta.cal`，`goCalibrate`），跳转到独立页 `pages/calibrate/calibrate`。
- 新建标定页：静止 5 秒（`CAL_TIME = 5000`）采样加速度 ax/ay/az，算出零点偏置（ax=均值、ay=均值、az=均值-1g），结果存 `wx.setStorageSync('zero_offset', {...})`。
- 标定期间对加速度做速度积分（vx/vy = ∫ a·g·dt），用于绘制漂移速度曲线。

## ECharts 接入（小程序）
- 引入 `echarts-for-weixin` 方案：`components/ec-canvas/`（ec-canvas 组件 + wx-canvas.js 适配层 + echarts.js）。
- echarts.js 为**按需精简构建**（echarts@5.5.1 仅折线图：LineChart + Grid/Tooltip/AxisPointer/MarkLine + CanvasRenderer），用 esbuild 打包成 CommonJS，约 489KB（全量约 1MB，避免主包超 2MB 限制）。
- 标定完成后用 ECharts 画 3 张图：加速度 X、加速度 Y（含 y=0 零点参考线 markLine）、标定期速度（vx+vy 双曲线）。
- 图表采用 `ec: { lazyLoad: true }`，标定结束后 `setData(..., cb)` 回调里再 `selectComponent(...).init(cb)` 手动初始化，避免 wx:if 容器未渲染导致取不到组件。
