## ECharts 接入（小程序）
- 引入 `echarts-for-weixin` 方案：`components/ec-canvas/`（ec-canvas 组件 + wx-canvas.js 适配层 + echarts.js）。
- echarts.js 为**按需精简构建**（echarts@5.5.1 仅折线图：LineChart + Grid/Tooltip/AxisPointer/MarkLine + CanvasRenderer），用 esbuild 打包成 CommonJS，约 489KB（全量约 1MB，避免主包超 2MB 限制）。
- 标定完成后用 ECharts 画 3 张图：加速度 X、加速度 Y（含 y=0 零点参考线 markLine）、标定期速度（vx+vy 双曲线）。
- 图表采用 `ec: { lazyLoad: true }`，标定结束后 `setData(..., cb)` 回调里再 `selectComponent(...).init(cb)` 手动初始化，避免 wx:if 容器未渲染导致取不到组件。

## 姿态虚拟零点（全局两个变量）—— 13:40 追加
- 新增 `utils/zero.js`：两个全局变量 `zeroRoll` / `zeroPitch`（度），语义 `roll' = wrap180(roll + zeroRoll)`，即施加在传感器 roll / pitch 上的偏移量（负值即减）。
  - 持久化 `wx.setStorageSync('wt_zero_v1', {roll, pitch, set})`，并挂 `app.globalData.zero`；`load()` 带模块级缓存，50Hz 调用无 IO。
  - API：`get / set / reset / setFromAngles / setFromSamples / apply`。`setFromSamples` 取原始采样均值并取负 → 当前姿势即 0°。
- `utils/witble.js` 的 `emit()` 统一 `zero.apply(d)`：所有页面拿到的 d.roll/d.pitch 已是零点后角度；原始值放 d.rawRoll / d.rawPitch，**标定永远基于原始值，重复标定不累加**。
- 页面：
  - `pages/calibrate`（零点标定页）新增「姿态虚拟零点（Roll / Pitch）」卡片：实时显示 当前姿态 / 传感器原始值 / 全局偏移量 + 已标定状态；按钮「重新标定零点」（采样 1.2s，`ZERO_TIME`）/「清除零点」。原 5 秒加速度标定卡改名「加速度零点标定」。
  - `pages/rehab`：「设定基准」→「标定零点」，标定时写全局零点（`zero.setFromSamples`）+ 记录 `baseYaw`（仅供小人朝向）；底部新增零点状态行，点它也可重标。onFrame 不再做 baseRoll/basePitch 二次扣除（避免与全局零点重复）。
  - `pages/wit` 姿态角卡片补一行「传感器原始值」；`index` / `mine` 文案同步为「标定零点」。
- 依据实测（WitMotion App 截图）：正确佩戴时 roll≈-0.05°、pitch≈-0.06°、accZ≈0.995g → 传感器基本水平，三轴与身体一一对应（侧倾←roll、俯仰←pitch）。
