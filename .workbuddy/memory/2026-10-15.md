## [01:35] 修复真机截图暴露的三个 UI bug + Q 版小人重做
- 用户反馈（截图）：①底部蓝牙设备面板一直露出来；②3D 小人畸形巨大被裁切；③箭头/姿态仪被 canvas 盖住；④提示条两行大字占半屏。
- Bug 根因：
  ① `.dev-panel` 常驻 DOM 但 CSS 无隐藏态（只有 transition 没有 translateY）→ 补 `transform: translateY(105%)` + `.show` 归零；`.root` 加 overflow:hidden 防止平移出屏引发滚动。
  ② canvas 缓冲区被设成 w×w 正方形而舞台是竖长条（拉伸变形）；旧小人腿部数学错误（脚底在 y=-1.6 沉入地面）；相机太近 → 重写 man3d.js。
  ③ canvas z-index:1 盖住无 z-index 的箭头/角度徽章/姿态仪 → 三者补 z-index:5。
  ④ 提示条 64→54rpx，默认文案「请佩戴好后点「设定基准」」一行可容纳。
- Q 版小人重做（chibi 风格）：大头(0.72)+眼睛高光+微笑圆环+腮红、蛋形躯干(缩放球)、短裤层、肩/肘/膝球关节、小鞋子(压扁拉长球)，脚底贴 y=0；相机 (0,2.6,9.4) fov40 取景全身约 70%；HemisphereLight+主光+逆光；待机呼吸动画+手臂摆动。
- initMan3d 改为量取 .stage 实际 rect × dpr 设置 canvas 缓冲区，宽高比匹配不再变形。
- 截图中顶部「● 已连接/展开」黑色悬浮条确认为微信原生调试浮层（全项目无此文案），非本代码产生。
