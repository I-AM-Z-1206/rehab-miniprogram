## 赛车页横屏修复：CSS 旋转 → 原生 pageOrientation（00:35）
- **故障现象**（真机截图）：进入赛车页，画面被压成屏幕中间一条竖条，内容整体转了 90°，位置/尺寸全错。
- **根因**：伪横屏用 CSS `transform: rotate(90deg)` + `width:100vh/height:100vw`，画布 CSS 尺寸在 webview 下没按预期撑开，canvas 缓冲区按错误尺寸建立；同时 touch 还手工做了 `(py, winW - px)` 的旋转换算，画布一错坐标全错。
- **结论**：查文档确认 **page.json 支持 `pageOrientation`**（基础库 2.4.0 auto / **2.5.0 landscape**），并且**只影响该页面**——之前「只能全局配置」的判断是错的，CSS 旋转方案整体废弃。
- 新实现：
  - `race.json` 加 `"pageOrientation": "landscape"`；canvas `position:absolute; inset:0; 100%×100%`；删除 `.stage` 旋转容器。
  - touch 直接 `engine.toDesign(t.clientX, t.clientY)`（toDesign 内部乘 dpr，按 CSS px 输入），不再手工旋转。
  - `fit()` 让开微信胶囊：可用宽度收到 `getMenuButtonBoundingClientRect().left - 10px`，画面右对齐（游戏计分板正好在设计坐标右上角，否则被胶囊压住），左侧留出的 letterbox 正好给返回键。
  - 旋转自愈：`Page.onResize` + `wx.onWindowResize` 双监听 + 延迟多次 refit（100/260/520/900ms）+ 帧循环每 30 帧比对 windowWidth/Height 兜底；尺寸未变不重建缓冲区（重建会闪）。
- 测试：`tools/race_page_test.js` 重写断言（横屏尺寸/不出画布/让开胶囊/触摸直接映射/画面中心↔设计中心/旋转重算/竖屏提示/卸载解绑），16 项全过；其它三套回归全过。

## 赛车手感调整：左右反向/灵敏度/50Hz/巡航速度（13:40）
- 需求（脑卒中患者）：左右颠倒、灵敏度不够、传感器 50Hz、给车初速度、前倾加速。
- **左右颠倒** → `motion.params.invertRoll = true`（只翻转向，不动油门）。
- **灵敏度** → `MOTION_TUNE` 覆盖引擎 DEFAULT_THERAPIST：maxAngle 20→**10°**、deadZone 3.5→**1.5°**、smoothing 0.35→**0.28**、assist 0.18→**0.08**、brakeAngle→**999**（康复期不设刹车，后倾只收油门，车不会停死）。
  - 写入方式：`seedMotionParams()` **一次性种子**写进引擎存储 `nrr_therapist_params_v1`（标记 `race_motion_seed_v1`），避免每次强行覆盖治疗师在游戏内面板调好的值；存储不可用才走 `applyMotionTune()` 内存兜底。改 MOTION_TUNE 要升 seed 版本。
- **50Hz** → `wit.setOutputRate(50)`，`ensureRate()` 只设一次（未连接则等 onReady 再设）。
  - 注意：之前射击页设的是 100Hz。
- **初速度 + 前倾加速** → 打包时改 `src/core/Player.js` 油门：`accel = (0.14 + 0.86*throttle) * accelFactor`（不倾身也有巡航，稳态约 1/3 最高速）；`startSession` 里补 `player.speed = diff.maxSpeed * 0.3`。
  - 关键认知：`dx = dt*steerRate*speedPct`，车不动 → 转向也没反应，所以「灵敏度不够」有一半是没速度造成的。
- build 插件新增 Player.js 的 onLoad 改造；产物自检加 `this.diff.maxSpeed*.3`（局部变量名会被 minify 改名，不能拿 `_cruise` 做自检）。
- 测试：`tools/race_page_test.js` 31 项全过（新增：康复参数已生效、左右反转、无刹车、参数落盘、50Hz、产物初速度）。

## 赛车页收尾：退出静音 / 只取 roll+pitch / 压延时（14:20）
- **退出后音乐还在响**
  - 根因：引擎 BGM 是 `setInterval` 调度的合成音，`require` 进来的 engine 是模块级单例，页面销毁不会自动停音频；WebAudio ctx 也不会自动回收。
  - 修：`pages/race/race.js` 加 `muteAudio(close)` / `unmuteAudio()`。
    - `onHide`：`stopBgm()` + `master.gain=0` + `ctx.suspend()`
    - `onShow`：`ctx.resume()` + `gain=0.35` + 对局中 `startBgm()`
    - `onUnload`：以上全部 + 停所有 source + `ctx.close()`（关键，否则返回上一页仍有残留音）
- **只取 roll/pitch**：`feedSensor` 改成只 `injectSample({angle:{roll,pitch,yaw:0}})`，不再构造 gyro/accel（引擎里这两个只喂 HUD 抖动评估，本项目用不到，也省每帧对象创建）。
- **延时（重点）**：KPI 量出来才发现滤波链是瓶颈——
  - `src/motion/KalmanFilter.js` 原 `q=0.02 / r=1.6`，稳态增益只有 **~0.10**，时间常数 ≈10 个样本，50Hz 下就是 **210ms 纯滞后**，叠 WMA 后 **250ms+**。
  - 打包时改成 `q=0.3 / r=1.0`（增益 ~0.30）：阶跃 90% 响应 **330ms → 117ms**，95% 433ms → 130ms；噪声抑制仍 ~0.2×（WT9011 角度噪声 ±0.2° 量级，看不出抖）。
  - 同时 `smoothing` 0.28→**0.18**、`assist` 0.08→**0**（回正辅助会吃掉小幅输入）、`rollSensitivity/pitchSensitivity` → **1.1**。
  - `ENGINE_SEED_KEY` 升 **v2**，让装过老版本的手机重新播种。
  - 新增 build 自检：产物里不能残留 `.02,1.6`。
- **精准**：`Player.js` 转向改成 `max(speedPct, 0.5)`，低速也保留一半转向能力。
  - 新增测试断言：阶跃响应 <160ms、满舵幅度与角度换算一致（8° → 0.841）。
