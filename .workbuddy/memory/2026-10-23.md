## 走钢丝（WR-01）视觉打磨与截图验证闭环

在 `games/wire/renderer.js` 完成一轮视觉收敛，全部改动**只影响绘制**，未触碰状态机 / 平衡模型 / 保险绳 / 计分：

- 钢丝透视：采样区间 `p ∈ [-0.62, 0.995]`（原先 -0.45 起，导致近端在 y=743 处出现悬空断口），线宽 `(1-p)^0.92`，`wireNearHalf = max(3.2, W*0.0084)`。
- 远端淡出：`_drawWire` 改为 4 段 band（alpha 1 / 0.72 / 0.46 / 0.24），每段自带由近到远的暗色剪影（`rgba(38,56,72, rim)`），解决细线在亮天空里"消失"和"被切断像管子"的问题。
- 角色站位：`BODY.legSpread` 9.5 → 5.4，鞋子压住钢丝中轴；影子椭圆 30×6.2 → 17×4.4。
- 短屏适配：`charY = min(H*0.775, H-170)`，避免底部平衡条压脚；模拟键盘 `bh/gap` 按 `H<680` 收缩。
- 保险绳：`anchorY = -18`（去掉被裁切的白色锚点圆），绳体 2.1→1.6、描边 3.6→2.8，捻纹只在 `tension>0.15` 出现。
- 结算页：按面板高度分三档排版（`ph<500` 迷你 / `<566` 紧凑 / 常规），迷你档把摆动分布并成一行、省略分项得分 tile，320×568 不再溢出。
- 背景：云层下移到信息条之下的可见天空带（y 0.19~0.30），`C.card` 0.93→0.97（防止绳索透过 HUD 卡片）。
- 介绍页：`scrim` 改为"顶部轻压暗 + 下半部 0.10→0.38"，天空/远山不再发灰；chips 改成白底深字。

验证方式（无需开发者工具）：`tools/wire-preview/` 用 esbuild 打包同一套代码到浏览器，Chrome headless 截图（`?bare=1&w=&h=&screen=`），逐张目视 + PIL 像素采样。`node tools/wire-headless-test.js` 7 组自检全绿。

## 经验

- 微信小程序 canvas 全 Canvas UI 下，**细线在浅色背景上会消失**，必须有"剪影层"；且分段 alpha 是唯一能在同一路径上做纵向淡出的可靠办法（Canvas 不支持沿路径的渐变 alpha）。
- `charY` 这类"看起来只是视觉"的常量，在 320×568 上会直接造成平衡条压脚，属于必须做 clamp 的布局参数。
- 结算页这类信息密集面板，用"三档排版 + 去掉重复信息"比整体缩放更可读。
